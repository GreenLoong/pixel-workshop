# pixel-workshop

基于 C++、Qt 6 和 OpenCV 4 开发的 Windows 桌面批量图像处理工具。

## 当前进度

- 已创建 Qt Widgets 与 CMake 工程。
- 已使用 Qt 6.11.1、MSVC 2022 x64 Kit 构建并运行窗口。
- CMake 已找到并链接 OpenCV 4.13.0。
- OpenCV 灰度转换、PNG 保存和重新读取验证已通过。
- 已实现图片选择、等比例预览、取消选择和读取失败提示；横图、竖图及损坏图片等场景待完成手动验收。
- 已实现窗口大小改变后的预览适配、OpenCV 灰度化和恢复原图。
- 已实现 PNG 另存为，输出重名时自动添加编号，避免覆盖已有文件。
- 已实现按像素调整尺寸、百分比预览缩放、限范围拖动和图片独立全屏预览。
- 已实现亮度与对比度对话框，支持组合使用灰度、尺寸、亮度和对比度。
- 打开图片时记住上次成功选择的目录，支持重启后继续使用。
- 两个参数对话框共用无标题栏样式；色调滑块支持点击轨道定位和拖动即时预览，确认后处理完整原图。
- 处理参数统一由 ImageProcessor::Options 保存，图像运算与 Qt 数据转换分离；批量处理仍待开发。
- 16 种参数开关组合、像素截断、原图保护检查通过；普通与 200% 显示缩放下的离屏交互检查通过。真实鼠标、触控板和部分文件异常场景仍需手动验收。

程序入口仅负责初始化应用和显示窗口。环境检查代码保留在 [OpenCV 环境验证示例](ImageBatchTool/OpenCV环境验证示例.md) 中，需要排查时单独使用。

## 开发环境

- Windows 64 位
- C++17
- Qt 6.11.1 Widgets
- MSVC 2022 x64
- CMake + Ninja
- OpenCV 4.13.0

本机配置方法和验收步骤见[环境配置文档](docs/环境配置.md)。项目范围、阶段计划和开发记录见[开发文档](开发文档.md)。

预览操作见[预览缩放与拖动](docs/预览缩放与拖动.md)，组合处理的参数和模块职责见[图像处理组合与模块设计](docs/图像处理组合与模块设计.md)。
