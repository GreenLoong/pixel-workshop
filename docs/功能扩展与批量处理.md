# 编辑功能扩展与批量处理

日期：2026-10-04

我按可运行阶段实现功能，每个阶段检查通过后单独提交并推送 GitHub。初始备份为 8a28cf9。

## 裁剪与旋转

“编辑 → 裁剪与旋转”提供自由、原图比例、1:1、4:3、16:9、3:4、9:16 裁剪，左右旋转 90°、任意角度旋转、水平和垂直翻转。

裁剪框使用图片场景坐标处理移动与边缘拖动，不能超出图片；参数记录为旋转和翻转之后的相对区域。确认后从完整原图计算，批量处理可复用相对区域。旋转展开画布保留整张图片，RGB 图片新增空白为白色，RGBA 图片新增空白透明。

未修改任何几何参数时确认保留原有尺寸设置。修改裁剪或旋转后清除输出尺寸设置，以实际裁剪结果为准，之后可再次“调整大小”。取消不修改主页。

处理和交互检查包括归一化裁剪、翻转、90°／180°旋转、任意角度展开、原图不被修改、非法参数拒绝和对话框参数映射。

颜色调整、撤销重做、背景分割与画笔修正、透明 PNG、文件夹批量任务和后台执行已实现；各项实现与验收记录如下。

## 颜色与光线

我采用左侧预览、右侧可滚动参数面板，包含亮度、对比度、曝光、饱和度、色温、色调、高光、阴影、清晰度和晕影。参数可以组合；重置只清除颜色和光线调整，保留几何参数。确认前使用缩略图，确认后从原图计算。

曝光以 2 的 EV 次幂调整；饱和度调整 HSV 的 S 分量；色温与色调调整通道平衡；高光／阴影按亮度权重调整；清晰度采用高斯模糊差分；晕影按距中心的距离衰减。算法与 Windows 照片应用不保证一致。

新颜色处理位于灰度之前，亮度和对比度位于灰度之后，以保持之前灰度像素验收规则。曝光、去饱和、暖色方向、阴影提亮、高光压暗、晕影和组合处理检查通过。

## 撤销与重做

我使用 Qt 的 QUndoStack 保存最多 50 次已确认参数。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。恢复原图也记录为一次编辑，打开新图片清空历史。历史保存参数而不保存放大位图，回退时从原图重新计算。

检查覆盖颜色恢复、灰度重做和恢复原图后的撤销。

## 背景编辑与透明图片

我默认使用 PPHumanSeg 自动分割人物，提供模糊、移除和替换背景；通用区域模式继续使用 GrabCut。替换支持纯色与图片；图片背景按输出尺寸铺满。通用区域模式中，主体范围框外作为背景样本，画笔可标记明确的前景和背景；支持撤销最近笔触与重置。调整几何坐标后清空笔触，避免沿用错误的位置。

预览限制到 1024 像素，在后台线程计算；150 毫秒合并连续调节，已有任务结束后计算最新参数，避免同时堆积多个分割任务。确认时从完整原图处理，分割蒙版从预览尺度映射回完整尺寸。透明区域用棋盘格显示，PNG 保留透明通道；颜色、灰度、尺寸处理保留原有透明度。

人像模式使用内置预训练模型，通用区域模式依赖颜色分割；复杂头发仍可能需要手工修正。模型和验证记录见[人像分割算法替换](人像分割算法替换.md)。取消不修改主页参数；异步预览、蒙版初始化、透明输出、三种背景模式和画笔修正检查通过。

## 文件夹批量处理与后台执行

我把逐张读取、处理、保存放到专用 QThread，界面仅接收进度和结果信号。开始时复制完整编辑参数并生成文件清单，不递归子目录。支持 PNG、JPG、JPEG、BMP、WebP、TIF、TIFF 扩展名；能否解码以 Qt 实际安装的图片插件为准，解码失败记录到结果表。

输入与输出目录通过规范路径比较，必须不同。逐张输出 `<原文件名>-result.png`，遇到重名自动编号。单张保存与批量保存共用新文件创建方法，使用 NewOnly 避免覆盖；写入失败清除本次创建的不完整文件。读取使用 QImageReader，支持中文路径并应用 EXIF 方向。

取消使用原子标志，不强制终止线程。当前图像运算结束后检查取消标志，再决定是否写入；已完成输出保留，未处理图片不再启动。关闭运行中的对话框会请求取消，等线程退出后关闭。结果表保留输入、实际输出路径和失败原因，可以导出带 UTF-8 BOM 的 CSV 报告。

检查覆盖两张正常图片加一张损坏图片、大小写扩展名、子目录排除、中文路径、透明度、原图摘要不变、重复运行自动编号、相同目录拒绝、无效输出路径、立即取消、中途取消、运行时关闭对话框。后台处理期间界面定时器保持响应，工作线程结束后才能启动下一次任务。

主页将编辑入口集中到“编辑图片”菜单，并增加批量处理按钮。取消某个编辑对话框不会改变主页，批量任务使用打开对话框时的参数快照。
