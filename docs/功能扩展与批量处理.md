# 编辑功能扩展与批量处理

日期：2026-10-04

我按可运行阶段实现功能，每个阶段检查通过后单独提交并推送 GitHub。初始备份为 8a28cf9。

## 裁剪与旋转

“编辑 → 裁剪与旋转”提供自由、原图比例、1:1、4:3、16:9、3:4、9:16 裁剪，左右旋转 90°、任意角度旋转、水平和垂直翻转。

裁剪框使用图片场景坐标处理移动与边缘拖动，不能超出图片；参数记录为旋转和翻转之后的相对区域。确认后从完整原图计算，批量处理可复用相对区域。旋转展开画布保留整张图片，新增空白暂为白色。

未修改任何几何参数时确认保留原有尺寸设置。修改裁剪或旋转后清除输出尺寸设置，以实际裁剪结果为准，之后可再次“调整大小”。取消不修改主页。

处理和交互检查包括归一化裁剪、翻转、90°／180°旋转、任意角度展开、原图不被修改、非法参数拒绝和对话框参数映射。

## 后续阶段

颜色调整、撤销重做、背景分割与画笔修正、透明 PNG、文件夹批量任务和后台执行，按完成情况补充实现与验收记录。

## 颜色与光线

我采用左侧预览、右侧可滚动参数面板，包含亮度、对比度、曝光、饱和度、色温、色调、高光、阴影、清晰度和晕影。参数可以组合；重置只清除颜色和光线调整，保留几何参数。确认前使用缩略图，确认后从原图计算。

曝光以 2 的 EV 次幂调整；饱和度调整 HSV 的 S 分量；色温与色调调整通道平衡；高光／阴影按亮度权重调整；清晰度采用高斯模糊差分；晕影按距中心的距离衰减。算法与 Windows 照片应用不保证一致。

新颜色处理位于灰度之前，亮度和对比度位于灰度之后，以保持之前灰度像素验收规则。曝光、去饱和、暖色方向、阴影提亮、高光压暗、晕影和组合处理检查通过。

## 撤销与重做

我使用 Qt 的 QUndoStack 保存最多 50 次已确认参数。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。恢复原图也记录为一次编辑，打开新图片清空历史。历史保存参数而不保存放大位图，回退时从原图重新计算。

检查覆盖颜色恢复、灰度重做和恢复原图后的撤销。

## 背景编辑与透明图片

我使用 GrabCut 分割主体，提供模糊、移除和替换背景。替换支持纯色与图片；图片背景按输出尺寸铺满。主体范围框外作为背景样本，画笔可标记明确的前景和背景；支持撤销最近笔触与重置。调整几何坐标后清空笔触，避免沿用错误的位置。

预览限制到 1024 像素，在后台线程计算；150 毫秒合并连续调节，已有任务结束后计算最新参数，避免同时堆积多个分割任务。确认时从完整原图处理，分割蒙版从预览尺度映射回完整尺寸。透明区域用棋盘格显示，PNG 保留透明通道；颜色、灰度、尺寸处理保留原有透明度。

这项功能依赖颜色分割，复杂头发和相近背景需要手工修正。我没有接入人像识别模型。取消不修改主页参数；异步预览、蒙版初始化、透明输出、三种背景模式和画笔修正检查通过。
