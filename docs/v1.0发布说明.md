# Pixel Workshop v1.0.0 发布说明

日期：2026-10-05。适用平台：Windows x64。交付状态：候选版，核心功能已定稿，实际设备人工验收尚未完成。

我将单张图片编辑、文件夹批量处理和后台执行作为 1.0 的完整交付范围。版本号由 CMake 统一生成，应用版本、Windows 文件属性和包内 manifest 使用同一版本。源码、运行包与 SHA256 随 GitHub 版本交付。

## 本版范围

- 读取 JPG／JPEG、PNG、BMP，记住打开目录，PNG 保存与重名自动编号。
- 整个预览区滚轮缩放、受限拖动、适应／实际大小切换、黑色背景全屏和 Esc 返回。
- 编辑页统一管理裁剪旋转、尺寸、颜色光线和背景参数，保留组合处理、会话撤销重做、取消与恢复原图。
- 按像素和百分比调整尺寸，保持比例，显示原图／当前／目标尺寸；Designer 的 resizepanel.ui 直接对应尺寸面板布局。
- 人像背景移除、模糊、纯色／图片替换，通用区域模式与前景／背景画笔修正，透明 PNG 输出。
- 独立批量参数与预设、逐图尺寸策略、后台逐张处理、进度／结果统计、取消和 CSV 报告。
- 单张后台任务只提交最新结果，保存与关闭流程保护未保存图片和编辑草稿。
- 分层模块共享同一处理实现，Qt Creator 目标分类，开发测试与交付自检独立配置。

## 构建与运行

本机和 CI 使用 Qt 6.11.1 MSVC 2022 x64、OpenCV 4.13.0、C++17、CMake 与 Ninja。源码入口、开关和部署命令见[Windows 构建与交付](Windows构建与交付.md)。

交付 `PixelWorkshop-1.0.0-rc1-windows-x64-setup.exe` 中文安装向导，提供开始菜单入口、可选桌面快捷方式、重装与卸载。安装器检测 Visual C++ x64 运行库，缺少时调用包内微软官方安装程序；Qt、OpenCV 与人像模型直接附带，安装过程中不需要联网。支持 Windows 10 1809 或更新的 x64 系统。

同时保留完整便携 ZIP。目标电脑不需要安装 Qt、OpenCV 或 Python。安装、自动自检与实际操作步骤见[另一台电脑验收](另一台电脑验收.md)。

## 使用边界

- 批量扫描当前目录，不递归子目录；输出统一为 PNG。
- 完整处理输出上限为 4000 万像素；预览使用缩略图，边缘细节可能与完整输出不同。
- 默认模型面向人像；其他主体使用通用区域模式，复杂发丝或边缘可能需要画笔修正。
- 取消会丢弃待提交结果或停止后续图片；已进入的 OpenCV 运算会完成当前调用。
- 本版交付 Windows x64；没有对其他系统宣称完成验收。

更多输出格式、递归批量、性能优化可在后续版本按实际需求加入，不影响本版核心流程定稿。
