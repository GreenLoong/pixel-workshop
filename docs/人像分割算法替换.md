# 人像背景分割算法替换

日期：2026-10-04。本文供我维护背景编辑、检查模型来源与复现验证。当前默认识别方式改为 PPHumanSeg 人像模型，通用区域模式继续使用 GrabCut。

## 问题与根因

证件照移除背景后，脸部保留，西装大部分被删除。我检查了原实现：主体范围框外直接标记为背景，GrabCut 根据颜色分布分组，没有“人物及其衣物”语义。主体贴近图像边缘时，衣服可能成为背景样本，影响框内其他相近颜色。

我在同一张 480×640 本机照片上对比两种算法。取宽度 10%～90%、高度 80%～98% 的衣物区域，计算输出 Alpha 平均值；0 表示透明，255 表示不透明。原区域算法约 12.95，新人像模型为 255。此结果只说明这张照片上的改进，不能推断所有图片的准确率。测试照片和结果不加入 Git 仓库。

## 方案选择

| 方案 | 接入方式与限制 | 本次选择 |
| --- | --- | --- |
| GrabCut | 已有 OpenCV 实现，需要区域／画笔，依赖颜色分布 | 保留为通用区域模式 |
| OpenCV Zoo PPHumanSeg | 约 6 MB ONNX，官方 C++ 示例，Apache 2.0；专用于人物 | 人像默认方案 |
| rembg | 提供多种模型与背景移除流程，通常涉及 ONNX Runtime／Python；每个权重需单独确认来源、许可证与兼容性 | 本次未引入整个框架 |

来源：[OpenCV Zoo PPHumanSeg](https://github.com/opencv/opencv_zoo/tree/47534e27c9851bb1128ccc0102f1145e27f23f98/models/human_segmentation_pphumanseg)、[推理参考](https://github.com/opencv/opencv_zoo/blob/47534e27c9851bb1128ccc0102f1145e27f23f98/models/human_segmentation_pphumanseg/pphumanseg.py)、[目录许可证](https://github.com/opencv/opencv_zoo/blob/47534e27c9851bb1128ccc0102f1145e27f23f98/models/human_segmentation_pphumanseg/LICENSE)、[rembg 项目](https://github.com/danielgatis/rembg)。

## 实现边界

我将 ONNX 原文件放入 `ImageBatchTool/resources/models`，通过 Qt 资源嵌入程序，运行时无需另行下载、Python 或联网。SHA-256 为 `552d8a984054e59b5d773d24b9b12022b22046ceb2bbc4c9aaeaceb36a9ddf24`，大小为 6163938 字节；载入时校验摘要。模型未修改，上游许可与说明保存在同目录并加入 Windows 运行包。

- `humansegmentation.cpp` 负责 OpenCV DNN CPU 推理，不访问窗口或文件。
- `ImageProcessing` 从内置资源提供只读模型字节，单张、预览和批量共用。
- 每个线程分别缓存 Net，避免不同任务同时修改同一个网络的输入状态。
- RGB 输入缩放到 192×192，按 `(像素 / 255 - 0.5) / 0.5` 归一化；保持 RGB 通道顺序。
- 输出为背景／人物两类概率，先还原到目标尺寸，再选择概率较大的类别，随后应用画笔与边缘柔化。
- 人像模式忽略原范围框的背景约束，范围调整入口禁用；通用区域模式启用范围框。
- 移除、替换、模糊共用同一前景蒙版；原图和原有透明通道继续保护。

PPHumanSeg 属于人物语义分割，192×192 输入不保证复杂发丝的精细抠图。非人像图片使用“通用区域”，或后续接入经过验证的通用主体模型。本次未训练模型。

## 使用与验证

1. 重新构建并启动最新程序，打开图片，进入“编辑图片 → 背景编辑”。
2. “识别方式”选择“人像（自动识别人物）”，默认即此模式；查看人物、衣物及背景。
3. 用保留／删除画笔修正，确认后保存 PNG。取消不修改主页。
4. 非人像选择“通用区域（手工选择范围）”，再调整范围与画笔。

构建要求 OpenCV 4.10 或以上并包含 dnn；本机仍使用 4.13.0。启用 `IMAGEBATCHTOOL_BUILD_TESTS=ON` 后运行 CTest。新增 `segmentation_tests` 检查内置模型、并发推理、画笔覆盖；可传入本机证件照路径，额外检查脸部与衣物保留、白色背景移除、背景替换和模糊。

本机照片还通过 `batch_tests` 的后台批量验证，以及 `dialog_interaction_tests` 的人像默认选项、范围入口禁用、切回区域模式和取消检查。未上传或在公开仓库保存测试照片。不同人物、复杂背景与不同电脑仍需继续验收。
