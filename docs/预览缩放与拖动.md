# 预览缩放与拖动

日期：2026-10-04

本文用于记录我在单张图片预览中增加的缩放和拖动功能，供后续开发、排错和验收使用。当前状态：实现完成，Release 构建与离屏交互检查通过；真实鼠标和触控板操作仍需手动验收。

## 需求和边界

我希望在主窗口状态栏右侧调整预览比例，也能通过滚轮查看图片细节。放大后的图片允许按住左键拖动，拖动到图片边缘时停止。

- 缩放范围为 1%～800%，100% 按图片的逻辑尺寸显示。
- 打开图片时自动适应显示区域并居中，小图片也可以放大至适应区域。
- 比例菜单、滑块和加减按钮控制同一个预览比例。点击滑块轨道直接跳到鼠标位置，按住后仍可继续拖动。
- 已打开图片时，鼠标位于预览视口内即可使用滚轮，包括图片周围的留白；继续沿用鼠标锚点和小图居中规则。
- 按住左键并移动鼠标即可拖动，无需等待长按计时。
- 图片在某个方向小于显示区域时，该方向保持居中；超过显示区域后允许拖动到两端边缘。
- “适应 / 100%”按钮在适应窗口和实际大小之间切换并居中。适应模式随窗口大小调整，手动缩放后保留选定比例。
- 同尺寸图像处理结果保留手动缩放；图片尺寸发生变化时重新适应窗口。
- 缩放和拖动只修改视图，不修改当前处理图片，也不改变保存结果的像素尺寸。
- 预设比例菜单按 800%、700%、600%、500%、400%、300%、200%、100%、75%、50%、25%、10% 降序排列，也允许输入 1%～800% 的任意整数比例。
- 右下角按钮和 F11 打开独立的图片全屏预览，黑色背景，只显示当前处理图片。Esc 或 F11 返回主页，保留主页的缩放和位置。
- 全屏和主页的预览均支持双击图片，在适应窗口与 100% 之间切换。
- 主窗口隐藏系统标题栏，菜单栏右上角提供最小化、最大化／还原和关闭。菜单栏空白处可拖动，双击空白处可最大化／还原；窗口外沿调用系统尺寸调整。
- 主窗口使用圆角背景壳、细边框和 Qt 阴影。最大化时去掉阴影留白。菜单栏右侧和状态栏按钮组外边距为 3px，按钮悬停使用圆角背景，关闭按钮深红悬停、淡红按下。

## 拆解与方案选择

我将功能拆成预览变换、拖动边界和状态栏交互。已有 QLabel 实现负责等比显示；增加拖动后，还需要处理图片偏移、裁剪、鼠标锚点和边界限制。

| 方案 | 需要维护的内容 | 我的选择 |
| --- | --- | --- |
| 在 QLabel 上继续自绘 | 缩放绘制、偏移、裁剪、拖动范围 | 暂不采用，新增交互代码较多 |
| 使用 QGraphicsView | 场景图片、比例、按钮与信号连接 | 采用，由 Qt 处理裁剪和拖动范围 |

## 实现

我保留现有 PreviewLabel 类名和 imageLabel 控件名称，将基类改为 QGraphicsView，减少主窗口其他代码的改动。

- 图片由 QGraphicsPixmapItem 保存和显示，场景范围设置为图片矩形。
- 通过绝对变换设置比例，避免生成占用大量内存的放大位图。
- 使用 ScrollHandDrag 处理左键拖动；滚动条隐藏，但其范围仍限制移动位置。
- 使用 AnchorUnderMouse 保持滚轮缩放的鼠标锚点。
- 我将轨道点击策略抽到 sliderstyle.h，主页缩放、亮度和对比度复用同一实现，数值映射与拖动由 Qt 提供。
- PreviewLabel 的 cornerRadius 属性指定视口圆角，主预览为 12px、色调预览为 8px、全屏为 0。根据边框厚度计算内部半径，用 Qt 遮罩裁剪图片；视口尺寸变化时重建遮罩，缩放和拖动时继续复用。
- 主窗口通过 addPermanentWidget 将缩放控件放到状态栏右侧。
- 预览发出 zoomChanged 信号后更新菜单和滑块，使用 QSignalBlocker 避免控件反向触发重复缩放。
- 未打开图片时禁用缩放控件，并显示占位文字。
- 全屏采用独立 QDialog，内部复用 PreviewLabel。关闭对话框即可返回，不移动主页的预览控件。
- 主窗口的背景壳采用 QFrame 与 QGraphicsDropShadowEffect，阴影只施加于背景壳。

关联源码：ImageBatchTool/previewlabel.h、ImageBatchTool/previewlabel.cpp、ImageBatchTool/mainwindow.cpp 和 ImageBatchTool/mainwindow.ui。

## 手动验收

1. 重新构建 release-clean 并运行，未打开图片时确认缩放控件禁用。
2. 打开横图和竖图，确认自动适应且比例正确。
3. 选择 100%、200%，使用滑块和加减按钮，确认比例同步。点击滑块靠右的轨道，确认直接跳到对应比例，再按住拖动。
4. 在图片细节处滚动滚轮，确认该位置附近仍留在鼠标下方；缩小后把鼠标移到预览窗口内的留白处，确认仍能放大和缩小，状态栏比例同步。
5. 放大后向四个方向拖动，确认到达边缘后停止；检查图片超过预览窗口后四角仍是圆角，改变窗口尺寸后继续保持。
6. 缩小图片后拖动，确认小于显示区域的方向保持居中。
7. 点击“适应 / 100%”，确认两个模式切换；在适应模式下调整窗口大小，确认图片重新适应显示区域。
8. 保存图片并核对像素尺寸，确认未受预览缩放影响。
9. 打开全屏预览，确认背景为黑色，测试滚轮、拖动和双击，再按 Esc 返回主页。
10. 在实际 Windows 窗口中检查菜单栏拖动、边缘调整尺寸、最小化与还原，以及按钮的 3px 外边距和关闭按钮颜色。

离屏检查不覆盖真实触控板滚动手感、不同显示器切换和 Windows 原生窗口交互。这些结果需要手动记录。

## 2026-10-04 修复记录

我确认主缩放滑块仍使用默认步进点击，因为之前的直接定位样式只在色调对话框内部定义。现在三个滑块复用同一个样式策略。

预览圆角失效的原因是样式表只绘制圆角边框，QGraphicsView 的内部视口仍为矩形。图片放大后铺满视口，会覆盖角落。我保留 QGraphicsView 的缩放与拖动，只为内部视口增加圆角遮罩。图片像素、保存尺寸、鼠标锚点与滚动范围不参与遮罩计算。

新增检查位于 ImageBatchTool/tests/dialog_interaction_tests.cpp，使用填满视口的纯色图，在 800% 缩放和窗口尺寸变化后核对四角不显示图像颜色、中心仍显示图像，以及比例保持不变。全屏模式另检查遮罩为空。

### 2026-10-04：滚轮响应范围修正

我将滚轮响应范围从图片像素矩形扩展到整个预览视口。原先 wheelEvent 检查 imageItem 是否包含鼠标对应的场景坐标，留白处直接忽略事件。现在只保留未加载图片和无纵向滚轮变化的检查；鼠标事件仍由 Qt 视口接收。

我新增缩小后在图片外留白处滚动的回归检查，确认 10% 放大至 12%、反向滚动回到 10%，并核对主页比例控件同步。主预览、色调预览、全屏预览和空预览检查均通过。
