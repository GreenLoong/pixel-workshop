# 应用图标来源与制作

日期：2026-10-04

我为 Pixel Workshop 制作了原创猫耳角色应用图标，结合画笔和 RGB 像素块体现图像编辑用途。银蓝与蓝紫配色对应当前界面的蓝色主色。

## 参考与来源

我检索了 [Lucide 图标库](https://lucide.dev/icons/) 的猫与调色板图标、[Lucide 许可证](https://lucide.dev/license) 和 [OpenMoji 图标库](https://openmoji.org/library/)。这些是形状与用途参考；应用图标使用内置 imagegen 生成，没有直接复制上述图标文件或现有动漫角色。

## 项目文件

- ImageBatchTool/resources/icons/app-icon.png：生成的透明背景原图。
- ImageBatchTool/resources/icons/app-icon.ico：16、24、32、48、64、128、256 像素的 Windows 图标封装。
- ImageBatchTool/appicon.rc：Windows 可执行文件图标资源。
- indicators.qrc 的 /app/icon.png 与 main.cpp：窗口和任务栏图标。

ICO 的多尺寸转换只用于图标格式封装，原始 PNG 保留。生成使用内置 imagegen，没有使用 API CLI。

## 生成提示词

Use case: logo-brand. Create one polished original desktop app icon for Pixel Workshop, a Qt/OpenCV image editor and batch photo processing tool. Subject: an adorable original anime catgirl artist face, chibi icon proportions, silver-blue bob hair, distinct pink-lined cat ears, expressive teal eyes, friendly smile. Include a single small paintbrush and a compact cluster of red green blue pixel squares to clearly communicate image editing. Composition: centered, bold recognizable face silhouette filling most of a square rounded blue-violet tile; generous safe margins for small icon rendering. Style: modern clean anime illustration, crisp outlines, simple shading, cobalt blue and lavender accents matching a modern light desktop UI. True transparent background outside the rounded tile. No lettering, no watermark, no existing anime character, no extra characters, no full body, no erotic styling. Needs to remain readable at 32px and 48px, with clean edge contrast.
