# 统一编辑页与交互修复

日期：2026-10-04。开发文档版本：0.13。

## 页面组织

我将主页面定位为文件入口与结果浏览：打开图片、编辑图片、另存为、文件夹批量处理。标题栏左上角只显示应用名称；最小化、最大化和关闭继续保留在右上角。原有打开与保存快捷键保留。

点击“编辑图片”或按 Ctrl+E 后，主窗口切换到编辑页，顶部提供裁剪旋转、颜色光线、尺寸、背景四个模式。四个模式共用位置和大小固定的左侧画布，参数统一放在右侧固定宽度的可滚动面板。预览可用滚轮缩放，浏览状态可拖动，顶部可以放大、缩小和切换适应 / 1:1。切换模式保留手动缩放与拖动位置。F11 查看当前编辑草稿的全屏结果，Esc 退出全屏。

“完成编辑”将全部参数应用到主图，随后回到主页；需要写入磁盘时再点“另存为”。“取消”或编辑页内的 Esc 放弃本次会话。关闭取色器时只关闭取色器。编辑页内可以撤销、重做和恢复原图；完成整个会话后，主页一次 Ctrl+Z 可以撤销此次会话。

## 背景操作

1. 在背景效果中选择模糊、移除或替换；“不处理背景”用于停用背景效果。
2. 人像采用内置模型；非人像选择通用区域，再点击“调整主体范围”，拖动框的边缘或四角。完整主体应位于框内。再次点击该按钮返回结果浏览。
3. 开启“手工修正”，选择“保留主体”或“删除背景”。移动鼠标时，黑白双圈显示实际笔刷范围；按住左键拖动绘制，松开后后台重新计算。
4. 手工修正显示原图，蓝色蒙版表示被删除区域，可以看到并补回误删内容。画笔直径按图片短边的百分比设置，滚轮缩放时笔圈同步变化；画笔模式中左键用于绘制，关闭手工修正后左键恢复平移。
5. “撤销笔触”撤销最近一次绘制；“重置背景”清除笔触、背景图片与自选颜色，并恢复初始主体范围。
6. 模糊强度只在模糊模式显示；颜色和背景图片按钮只在替换模式显示。取色器使用不透明白底与深色文字。
7. 通用区域模式需要主体和背景两类标记。范围覆盖整图且没有背景标记时，先保留原图并提示缩小范围或补画背景；主体被全部删除时，可撤销笔触或用保留画笔补回。样本不足时按手工蒙版预览，标记足够后自动恢复分割，预览和输出采用相同规则。

## 实现边界

我使用 QStackedWidget 切换主页与编辑页。EditorPage 管理会话草稿、模式导航和本地历史；各模式复用原有参数面板。DialogAppearance 负责把同一参数面板嵌入页面，隐藏独立窗口的标题和确认区域。单张与批量继续使用 ImageProcessing / ImageProcessor 管线，原图始终保留。

EditorPage 持有常驻的 BrushPreview，各模式借用同一画布，不改变其父对象。切换时先释放旧参数面板及选择框，清理画笔回调，再创建新面板；结束会话时先释放参数控制器，再清空画布。尺寸模式可沿用已有结果预览，只在目标尺寸实际变化时更新；切页不再安排延迟适应窗口。裁剪需要展示未裁剪画面，背景手工修正需要展示原图及蒙版，这些模式保留各自的显示内容，但画布边界保持一致。

SelectionItem 统一处理裁剪和主体范围框的命中与光标：左右边为水平、上下边为垂直、四角为对角调整，框内为移动。命中距离以屏幕像素换算，缩放后仍容易抓住边缘。

BrushPreview 在视口上绘制笔圈，笔触仍记录为归一化坐标。背景预览使用后台任务及短延迟合并更新；修正时额外取得删除蒙版作可视化。较大图片使用缩略预览，完整输出在确认时从原图计算；预览细节、预览的 1:1 与完整图片像素视图可能不同，可用 F11 检查完整结果。

修改裁剪或旋转仍会清除目标尺寸及背景笔触，因为它们依赖图像坐标；单纯切换模式不会清除这些设置。批量处理使用已完成编辑的参数，不读取尚未完成的草稿。

## 验证

我新增检查覆盖裁剪各方向光标、编辑页内参数组合、尺寸比例联动、草稿撤销重做、取消保护、会话整体撤销；背景检查实际发送鼠标按下 / 拖动 / 松开事件，确认笔触写入并改变透明蒙版，同时检查笔圈尺寸反馈、模式专属控件显隐与取色器底色。

本次增加四个模式切换检查：始终使用同一个画布对象，边界坐标一致，手动倍率与中心位置不变；从调色结果进入尺寸模式不会再次提交图片刷新。
