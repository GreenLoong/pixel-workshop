# 开始使用与另一台电脑验收

适用版本：v0.19.0 Windows x64 候选包。日期：2026-10-04。

我把 Qt、OpenCV、图片格式插件、人像模型和自检工具放入运行包，目标电脑不需要安装 Qt、OpenCV、Python 或开发工具。先完成下列检查，再确认实际交付。

## 开始使用

1. 将 ZIP 整体解压到可以写入的目录，例如桌面下的 `PixelWorkshop`。不要直接在压缩软件中启动程序。
2. 双击 `ImageBatchTool.exe`。打开图片后点击“编辑图片”，在顶部切换裁剪旋转、颜色光线、尺寸、背景。点击“完成编辑”应用，使用“另存为”保存 PNG。
3. 若提示缺少 `VCRUNTIME` 或 `MSVCP`，先安装包内的 `vc_redist.x64.exe`（如果存在），或者从 [Microsoft 官方页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) 安装 x64 Visual C++ 运行库后重试。
4. `manifest.json` 记录版本、源码提交及文件 SHA256；`licenses` 保存随包依赖的许可证。原始图片和模型推理都在本机处理。

## 自动检查

在解压目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify-package.ps1
```

此参数只对本次进程有效。脚本核对文件 SHA256，清除子进程中的开发环境路径，调用自检工具，然后启动并正常关闭主窗口。自检覆盖中文路径、大图后台处理、灰度和亮度组合、尺寸、透明 PNG、重名编号、含坏图的批量任务、取消和内嵌人像模型。生成 `verification-result.json` 表示这些自动检查通过，人工交互仍标记为 pending。

脚本在包内创建临时测试图片并自动清理，不使用我的真实照片。完整解压后的目录需要写入权限。失败时保留终端错误内容，并记录 `manifest.json` 中的版本与提交标识。

## 人工检查

我在另一台未安装 Qt/OpenCV 的 Windows 电脑上按下面清单试运行。通过后勾选；出现问题时写下触发步骤、实际结果和预期结果。

- [ ] 程序启动和反复关闭正常；重新打开图片默认进入上次目录。
- [ ] 中文目录中的 JPG、PNG、BMP 可读取；透明 PNG 可显示和保存，原文件保持不变。
- [ ] 预览区留白上也能滚轮缩放；超过 100% 后拖动有范围限制，圆角与百分比显示正常。
- [ ] 全屏是黑色背景；滚轮、拖动可用，双击切换适应／实际大小，Esc 返回。
- [ ] 四个编辑模式切换时画布位置稳定；快速拉动滑块界面仍可操作，旧结果不会覆盖最新参数。
- [ ] 裁剪边角显示对应光标；尺寸保持比例；灰度、尺寸、颜色和背景可组合生效。
- [ ] 背景颜色选择正常；保留主体／移除背景画笔有尺寸反馈，确认后的 PNG 透明结果正确。
- [ ] 有未保存修改或草稿时，关闭／打开另一张图提示保存、放弃、取消；取消保存后仍留在当前图。
- [ ] 批量输入横图、竖图、小图和一张坏图，长边模式分别保持比例，小图默认不放大；坏图失败后继续其他文件。
- [ ] 批量取消保留已完成输出，不覆盖原文件；结果计数与 CSV 对应，重名结果自动编号。
- [ ] 自定义预设关闭后重新打开仍可选择；修改批量参数不改变主页图片。
- [ ] 实际常用的大图可以完成编辑和保存；记录图片像素、Windows 版本和显示缩放比例。
