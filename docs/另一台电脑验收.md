# 开始使用与另一台电脑验收

适用版本：v1.0.0 Windows x64 候选包。日期：2026-10-05。实际设备人工验收尚未开始，下面的勾选项保留为待执行清单。

我把 Qt、OpenCV、图片格式插件、人像模型和自检工具放入运行包，目标电脑不需要安装 Qt、OpenCV、Python 或开发工具。先完成下列检查，再确认实际交付。

## 开始使用

1. 推荐下载 `PixelWorkshop-1.0.0-rc1-windows-x64-setup.exe`，复制到 Windows 10 1809 或更新的 x64 电脑，双击进入中文安装向导。默认安装到当前用户的程序目录，可选创建桌面快捷方式。
2. 若系统缺少所需的 Visual C++ 运行库，向导会启动随包附带的微软官方安装程序；允许该程序的系统权限提示。整个安装过程不需要联网下载 Qt、OpenCV 或模型。
3. 安装后从开始菜单的“Pixel Workshop”启动。打开图片后点击“编辑图片”，在顶部切换裁剪旋转、颜色光线、尺寸、背景。点击“完成编辑”应用，使用“另存为”保存 PNG。
4. Windows“设置 → 应用 → 已安装的应用”中可以卸载 Pixel Workshop；卸载不主动删除我后来保存的图片或用户设置。安装程序尚未进行项目代码签名，来源和完整性可通过 Releases 的 SHA256 核对。
5. 若使用便携 ZIP，先整体解压到可以写入的目录，再启动 `ImageBatchTool.exe`。缺少运行库时先安装包内的 `vc_redist.x64.exe`。不从压缩软件内直接启动。

`manifest.json` 记录版本、源码提交及文件 SHA256；`licenses` 保存随包依赖的许可证。原始图片和模型推理都在本机处理。

## 自动检查

在安装目录或完整解压后的目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify-package.ps1
```

此参数只对本次进程有效。脚本核对文件 SHA256，清除子进程中的开发环境路径，调用自检工具，然后启动并正常关闭主窗口。自检覆盖中文路径、大图后台处理、灰度和亮度组合、尺寸、透明 PNG、重名编号、含坏图的批量任务、取消和内嵌人像模型。生成 `verification-result.json` 表示这些自动检查通过，人工交互仍标记为 pending。

脚本在包内创建临时测试图片并自动清理，不使用我的真实照片。完整解压后的目录需要写入权限。失败时保留终端错误内容，并记录 `manifest.json` 中的版本与提交标识。
